Connect to Replicate

Video Studio uses AI video models on Replicate. You pay Replicate per video; this app is free.

  1. Sign up at replicate.com and add a payment method under Billing.
  2. Create a token at API tokens and paste it here.

The token is saved in video-studio/.env on this computer and never shown in the browser again.
